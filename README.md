# The Hotel Lobby AI Guide

The Hotel Lobby AI is a browser-based tool for creating a short two-person rap video from two authorized adult photos, or one clear shared photo containing both authorized adults.

## What this guide covers

- choosing clear, front-facing photos with visible facial details;
- avoiding heavy occlusion, extreme crops, and mixed lighting;
- selecting a studio scene and generation settings;
- writing a concise prompt for a two-person performance;
- reviewing a private result before downloading it.

A Standard 720p, 12-second generation uses 10 credits. Render time varies by model and provider queue. Confirmed generation or delivery failures return the credits used by that attempt.
